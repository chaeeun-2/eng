두 서브에이전트를 순서대로 돌린다. **번역 → HTML 빌드.**

## 원문

$ARGUMENTS

## 1단계 — 번역

1. `Agent` 툴로 `subagent_type: "speak"`, `run_in_background: false` 호출.
2. 위 "원문" 블록의 내용을 **그대로** 전달한다.
   - 원문이 비어 있으면 에이전트를 호출하지 말고, 바로 직전 대화에서 사용자가 준
     한국어 내용을 대상으로 삼는다. 그것도 없으면 무엇을 번역할지 한 줄로 물어본다.
   - 파일 경로나 URL이면 경로/URL을 그대로 넘긴다. 에이전트가 직접 읽는다.
3. 돌려받은 결과를 **한 글자도 바꾸지 말고 전부** 사용자에게 출력한다.
   서브에이전트 출력은 사용자에게 보이지 않으므로 반드시 릴레이해야 한다.
4. 결과 앞뒤에 자체 요약·해설·인사말을 덧붙이지 않는다.

## 2단계 — HTML 뷰

번역을 출력한 **다음에**, `Agent` 툴로 `subagent_type: "speak-html"`,
`run_in_background: false` 호출. 아래를 전달한다.

- 한국어 원문 전문 (파일/URL이었으면 그 경로도 같이)
- 1단계에서 받은 영어 번역 전문 (밑줄 워딩 목록·대안 표현 목록 포함)

돌려받은 완료 보고는 번역문 아래에 **짧게 한 덩어리로** 붙인다. 길게 늘이지 않는다.

번역이 실패했거나 원문이 없으면 2단계는 건너뛴다.
사용자가 "번역만" 이라고 했으면 1단계에서 멈춘다.
