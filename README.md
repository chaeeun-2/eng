# ENG — 영어 학습 에이전트

단어와 추천 문장을 모아두고, 정리·검색·복습까지 하는 개인 학습 저장소.

## 구조

```
ENG/
├── SCHEMA.md          데이터 스키마 정의 (필드, 규칙)
├── index.html         GitHub Pages 진입점 → views/wordlist.html로 보냄
├── .claude/
│   ├── agents/speak.md       번역 서브에이전트 (한 → 영)
│   ├── agents/speak-html.md  대조 뷰 빌드 서브에이전트
│   └── commands/speak.md     /speak 슬래시 커맨드
├── data/
│   ├── vocab.jsonl    ← 단일 소스. 단어 1개 = 1줄
│   ├── raw/           붙여넣은 원본 백업
│   └── speak/         /speak 번역 결과 (한↔영 대응 마커가 붙은 JSON)
├── scripts/
│   ├── validate.py    무결성 검사 (예문·해석 필수 강제)
│   ├── build_views.py jsonl → 마크다운 생성 (build_html.py도 함께 실행)
│   ├── build_html.py  jsonl → 표 형태 HTML 생성
│   ├── build_pwa.py   manifest·service worker·아이콘 생성 (홈 화면 추가 + 오프라인)
│   └── build_speak_html.py  data/speak/*.json → 한↔영 대조 HTML 생성
└── views/             읽기용 (자동 생성, 직접 수정 금지)
    ├── wordlist.html  표 단어장 — 표제어·뜻·예문·해석 4열, 검색·정렬·품사 필터·뜻 가리기·읽어주기
    ├── wordlist.md    전체 단어장 (abc순 고정)
    ├── by-tag.md      주제별 색인
    ├── manifest.webmanifest · sw.js · icons/   PWA 껍데기
    └── speak/         번역 대조 뷰 (index.html이 목록) — 공개 저장소에서는 제외
```

`views/wordlist.html`은 브라우저로 그냥 열면 된다 (`open views/wordlist.html`).
<kbd>/</kbd> 검색, <kbd>h</kbd> 뜻 가리기, <kbd>s</kbd> 정렬 전환, <kbd>Esc</kbd> 읽기 중지.
가린 상태에서 칸을 누르면 그 칸만 열린다.

**정렬** — 툴바 왼쪽 `abc순 / 최근순` 토글. 최근순은 등록일 내림차순이고,
같은 날 등록된 단어는 jsonl에 쓰인 순서의 역순(나중에 넣은 것이 위)이다.
최근순일 때만 표제어 아래에 등록일이 표시된다. 선택은 브라우저에 저장돼 다음에 열 때도 유지된다.
검색·품사 필터와 독립이라 겹쳐서 쓸 수 있다.

## 모바일에서 보기

GitHub Pages로 배포한다. 단어장 부분만 공개되고, `/speak` 결과물은 `.gitignore`로 빠진다
(사내 업무 내용이라 공개 저장소에 올리지 않는다 — 로컬에는 그대로 남고 기능도 정상 동작).

```
python3 scripts/build_views.py     # 빌드
git add -A && git commit -m "단어 추가"
git push                            # 1~2분 뒤 반영
```

- 주소: https://chaeeun-2.github.io/eng/ (루트로 들어가면 단어장으로 넘어간다)
- **홈 화면에 추가** — 아이폰 Safari에서 주소를 열고 공유 → 홈 화면에 추가.
  주소창 없는 전체 화면으로 뜨고 아이콘이 생긴다
- **오프라인** — service worker가 단어장·폰트·아이콘을 캐시한다. 지하철에서도 열린다.
  온라인일 때는 항상 최신본을 먼저 받으므로(network-first) 갱신이 밀리지 않는다.
  캐시 버전은 `vocab.jsonl` 해시라 단어가 바뀌어야만 낡은 캐시를 버린다
- **카드 모드** — 780px 이하에서는 표가 아니라 카드 한 장이 화면을 채운다.
  화면 아래 `‹ 12 / 238 ›` 바의 화살표로 앞뒤 단어를 넘긴다. 양 끝에서는 화살표가 꺼진다.
  카드 차례는 현재 정렬·검색·품사 필터를 그대로 따르고, 그 셋 중 하나가 바뀌면 첫 카드로 돌아간다.
  카드가 길면 안에서 세로로 스크롤되며 표제어는 카드 머리에 고정된다
- 좁은 화면에서는 툴바가 2줄로 접힌다. 아래쪽 도구 띠는 옆으로 밀어서 쓴다.
  키보드 단축키 안내는 폰에서 숨긴다
- 커밋 이메일은 저장소 로컬 설정으로 GitHub noreply 주소를 쓴다 (회사 메일이 공개되지 않게)

**아이폰 읽어주기 주의** — 무음 스위치가 켜져 있으면 소리가 안 난다. 음성 목록도
설정 → 손쉬운 사용 → 콘텐츠 말하기에서 받아둔 것만 뜬다.

## 기능

**완료 표시** — 표제어 아래 `완료` 버튼을 누르면 다 외운 단어로 표시된다.

- 완료한 단어는 목록 **맨 뒤로** 밀린다. 그 안에서는 현재 정렬(abc순/최근순)을 그대로 따른다
- 카드 모드에서 누르면 그 자리에 다음 단어가 올라온다 — 누르고 넘어가기를 반복하면 된다
- 다시 누르면 해제되고 원래 자리로 돌아간다
- 툴바 오른쪽에 `278개 · 완료 12`처럼 진행 상황이 붙는다
- **저장 위치는 브라우저(localStorage)다.** 기기마다 따로 관리되고 `vocab.jsonl`에는 쓰이지 않는다.
  사파리는 오래 안 쓴 사이트의 저장값을 지울 수 있으니, 홈 화면에 추가해 앱으로 쓰는 편이 안전하다

**읽어주기** — 표제어와 예문 옆 스피커 버튼을 누르면 영어 발음을 읽어준다.
브라우저 내장 Web Speech API를 쓰므로 API 키가 필요 없고, macOS는 시스템 음성이라 오프라인에서도 된다.

- 툴바 `속도` 버튼 — 1.0× → 0.85× → 0.7× 순환. 섀도잉엔 0.7×가 편하다
- 툴바 음성 드롭다운 — 설치된 영어 음성 목록. 바꾸면 바로 미리듣기가 나온다
- 기본 음성은 점수제로 고른다: Premium(+40) > Enhanced(+30) > 이름 선호순 > en-US > 로컬 음성.
  즉 `Ava (Premium)`이 깔려 있으면 그게 1순위
- 속도·음성 선택은 localStorage에 저장돼 다음에 열어도 유지된다
- 재생 중 같은 버튼을 다시 누르거나 <kbd>Esc</kbd>를 누르면 정지
- 음성 합성을 지원하지 않는 브라우저에서는 버튼과 드롭다운이 숨겨진다

음성 품질을 올리려면 시스템 설정 → 손쉬운 사용 → 말하기 → 시스템 음성 → 사용자화에서
`Ava (Premium)`이나 `Samantha (Enhanced)`를 내려받으면 된다.

데이터 추가 후: `python3 scripts/validate.py && python3 scripts/build_views.py`

## 원칙

**모든 항목은 예문과 한국어 해석을 반드시 갖는다.** 뜻만 외우면 쓸 줄 모르게 되므로,
예문 없는 항목은 등록하지 않는다. `validate.py`가 이를 강제한다.

## 쓰는 법

**데이터 추가** — 형식 신경 쓰지 말고 그대로 붙여넣기. 정규화는 에이전트가 함.

**주요 요청 예시**
- `오늘 복습할 단어 뽑아줘` — `srs.due`가 오늘 이전인 항목
- `business 태그 단어장 만들어줘` — `views/`에 마크다운 생성
- `이 단어들로 퀴즈 내줘` — 뜻/문장 빈칸 테스트
- `run into랑 bump into 차이` — `confusables` 기반 비교
- `내가 자주 틀리는 패턴 분석해줘` — `srs.lapses` 상위 항목 분석

## /speak — 한→영 번역

`/speak <한국어 원문>` — 비즈니스 발표·회의에서 **그대로 말할 수 있는** 영어로 옮긴다.
텍스트, 파일 경로(`.txt` `.md` `.pdf` `.html`), URL 모두 받는다.

- 톤: 비즈니스-일상 구어체 (축약형·구동사·짧은 문장, 문어체 금지)
- 어휘: CEFR B1~B2. 문학적·현학적 단어는 쓰지 않음
- AI/콘텐츠 전문용어는 원어 그대로 적극 사용
- 그중 **업계에서만 쓰는 워딩**은 <u>밑줄</u> + 뜻 목록으로 따로 정리

번역이 끝나면 `speak-html` 에이전트가 이어서 대조 뷰를 만든다.
→ `data/speak/YYYY-MM-DD-<슬러그>.json` (대응 마커 포함) → `views/speak/<같은 이름>.html`

**대조 뷰에서 되는 것**
- 왼쪽 한국어 / 오른쪽 영어 나란히. 좁은 화면에서는 위아래로 접힌다
- 문장 옆 스피커 버튼 → 영어 발음 재생. 툴바 `전체 재생`은 처음부터 순서대로 읽어준다
- **단어에 마우스를 올리면 반대쪽 언어의 대응 단어가 같이 하이라이트**된다.
  누르면 고정, 다시 누르면 해제
- <kbd>h</kbd> 영어 가리기 (섀도잉용, 가린 칸을 누르면 그 칸만 열림) ·
  <kbd>p</kbd> 전체 재생 · <kbd>Esc</kbd> 정지
- 아래에 업계 전용 워딩 뜻풀이와 대안 표현 정리
- `views/speak/index.html` — 지금까지 번역한 것 목록

대응 관계는 JSON 문장 안에 `[[1:덩어리]]` 마커로 적는다. 같은 번호끼리 짝.
`*`를 붙이면(`[[2*:파인튜닝]]`) 업계 워딩으로 보고 밑줄까지 긋는다.
포맷 예시는 `data/speak/2026-09-08-example.json`.

JSON을 손으로 고쳤으면 `python3 scripts/build_speak_html.py`로 다시 빌드한다.
`views/speak/`의 HTML은 직접 고치지 않는다 (덮어쓰기됨).

번역만으로는 `vocab.jsonl`에 등록하지 않는다. 밑줄 워딩 중 뜻을 물어보면 그때 적립된다.

## 자동 적립

대화 중 뜻을 물어본 단어·관용어는 따로 요청하지 않아도 에이전트가 이 저장소에 등록한다.
(원본 → `data/raw/`, 정규화 → `data/vocab.jsonl`, 검증·뷰 재생성까지 자동)
